APLIKASI ABSENSI MAHASISWA
==========================

Isi folder:
- index.html : struktur halaman dan form
- style.css  : desain/tampilan aplikasi
- script.js  : validasi, event, logika, dan perhitungan

Cara menjalankan:
1. Pastikan ketiga file berada di folder yang sama.
2. Klik dua kali index.html untuk membukanya di Chrome, Edge, atau browser lain.
3. Isi nama, NIM minimal 5 digit, kelas, status, dan jam masuk.
4. Klik Simpan Absensi untuk melihat hasil.
5. Klik Reset untuk menyembunyikan hasil dan mengatur ulang form.

Aturan keterlambatan:
Batas waktu adalah pukul 08.00. Jika status Hadir dan jam masuk setelah 08.00,
program menghitung selisih waktu dalam menit.

Konsep pemrograman:
- Variabel dan tipe data: String, Number, Boolean.
- Operator aritmatika: +, *, -.
- Operator perbandingan: ===, >.
- Operator logika: AND (&&), OR (||), NOT (!).
- Event: submit dan reset.
- Validasi: nama, NIM, dan kolom wajib.
- Output: hasil absensi ditampilkan pada halaman.
